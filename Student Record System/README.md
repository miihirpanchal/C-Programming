******************************** Student Records System ************************************

A student records management program written in C.

The program is designed to store and manage student information through a simple menu-driven interface.

Features
Add student records
Display student details
Search for a student
Manage student information
Concepts Used
Structures
Arrays
Functions
Loops
Conditional statements
String handling
How to Run

Compile:

bash
gcc main.c -o student_records


Run:

bash
./student_records

Purpose

Created to practise using structures and organizing related information in C. It also helped me understand how basic record management systems work.
