Running the Programs

You need a C compiler such as GCC to compile and run these programs.

For example:

bash
gcc main.c -o program
./program


On Windows, you can run:

bash
gcc main.c -o program.exe
program.exe


Some projects may have different compilation instructions depending on their source files.
