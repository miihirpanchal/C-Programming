********************************** Matrix Multiplication ***************************************

A C program that performs multiplication of two matrices.

The program takes matrix elements as input, checks whether multiplication is possible and calculates the resulting matrix.

Features
Accepts matrix dimensions
Takes matrix elements as input
Checks multiplication compatibility
Calculates the product of two matrices
Displays the resulting matrix
How to Run

Compile:

bash
gcc main.c -o matrix


Run:

bash
./matrix

Concepts Used
Two-dimensional arrays
Nested loops
Functions
Conditional statements
Matrix operations
Purpose

Built to practise working with two-dimensional arrays and understand how matrix multiplication works in C.
