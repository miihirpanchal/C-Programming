************************************* Calculator *****************************************

A simple calculator program written in C.

The program takes input from the user and performs basic arithmetic operations.

Features
Addition
Subtraction
Multiplication
Division
How to Run

Compile the program:

bash
gcc main.c -o calculator


Run it:

bash
./calculator


On Windows:

bash
calculator.exe

Concepts Used
Functions
Conditional statements
Switch case
User input and output
Basic arithmetic operations
Purpose

Built as a small C project to practise implementing arithmetic operations and handling user input.
