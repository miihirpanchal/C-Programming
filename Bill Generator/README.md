*********************************** Bill Generator ***************************************

A simple bill generation program written in C.

The program takes the required details and calculates the total bill based on the entered items and their prices.

Features
Enter item details
Enter quantity and price
Calculate item totals
Calculate the final bill
Display bill details
How to Run

Compile:

bash
gcc main.c -o bill


Run:

bash
./bill

Concepts Used
Structures
Arrays
Loops
Functions
Arithmetic operations
User input and output
Purpose

Created to practise handling records, performing calculations and displaying formatted output using C.
