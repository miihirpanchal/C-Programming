*************************************** Parser *******************************************

A small parser project implemented in C.

The project focuses on reading input and processing it according to the parsing logic implemented in the program.

Features
Reads input from the user or source file, depending on the implementation
Processes input using parsing logic
Displays the result of parsing
Technologies
C Programming Language
Standard C libraries
How to Run

Compile the program:

bash
gcc main.c -o parser


Run it:

bash
./parser

Concepts Used
String handling
Conditional statements
Loops
Functions
Input processing
Purpose

Built to practise working with strings and understand how parsing logic can be implemented in C.
